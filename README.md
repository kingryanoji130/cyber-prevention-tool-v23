## Overview

cyber-prevention-tool gives organizations a hands-on method for teaching employees how to recognize phishing. Its simulation, reporting, and training workflow helps security teams observe how users handle suspicious messages and turn those results into more effective awareness efforts.

The application is intended for enterprise use and can be hosted on an organization's own infrastructure. Security teams, IT departments, and training coordinators can use it to run repeatable campaigns, work with reusable templates, examine response data, and provide structured learning material in a controlled environment.

## Running a campaign

The usual process is:

1. Choose an existing phishing template or prepare a new one.
2. Set up the simulation for the intended team, audience, or department.
3. Start the awareness exercise.
4. Examine employee response reports once the exercise is complete.
5. Use the findings to refine the training material.
6. Run future exercises with revised templates and scenarios.

A basic deployment sequence can include:

- Copying the project into the hosting environment
- Revising template content when required
- Publishing the simulation for the target team
- Gathering reporting information and training results
